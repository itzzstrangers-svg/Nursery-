SMART NURSERY INFORMATION PORTAL - MOBILE / GITHUB PAGES VERSION

This version uses ONLY:
- HTML
- CSS
- JavaScript

It does NOT require:
- PHP
- MySQL
- XAMPP

HOW TO USE ON MOBILE:
1. Install Acode (or another HTML editor) on Android.
2. Create a folder named smart-nursery.
3. Create these three files:
   index.html
   style.css
   script.js
4. Paste the corresponding code into each file.
5. Open index.html in Acode/browser to test.
6. Upload all three files to your GitHub repository.
7. Enable GitHub Pages.
8. Open your github.io website.

IMPORTANT:
- Nursery details in this demo are placeholders. Replace them with real local nursery information after getting permission.
- The contact form is a front-end demo; it does not send/store data on a server.
- Plant information is educational/general and should be checked for local growing conditions.
